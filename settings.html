What can I import? 
JSON: a backup exported from here.
CSV: the first row must name the columns.
  date       2026-10-05 or 05/10/2026
  name       payee or description
  amount     a number
  type       in / out  (or debit / credit)
  category   optional
  account    optional
  note       optional
Instead of "type" you can use separate "debit" and
"credit" columns, or negative amounts for money out.
Rows already here are skipped.
